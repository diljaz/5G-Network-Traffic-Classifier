\begin{center}
{\Large{\bf{ABSTRACT}}}
\end{center}


This project presents an automated system for pose detection and classification, specifically designed for traditional performing arts. The system focuses on capturing and analyzing distinct poses and gestures inherent to various classical performances, using Kathakali, a classical art form from Kerala, as a primary example to guide dataset creation and pose analysis.

To support this system, a comprehensive dataset of annotated images is being developed, showcasing characteristic poses, hand gestures, and expressions in Kathakali. Each image and video frame is meticulously labeled to identify key movements, gestures, and costume details, essential for achieving accurate pose classification. This annotated dataset enables the system to interpret sequences of predicted poses, fostering continuity and context within performances. By iterating through pose sequences, the system provides a consistent interpretation of complex movements, which is applicable across different art forms.

This generalized approach aims to support cultural preservation efforts and deepen our understanding of traditional performing arts. The Kathakali dataset, as a foundational example, will further be used to train object detection models. These models will empower the system to recognize and classify poses in real-time, facilitating advanced applications in automated pose analysis for various classical performing arts.
